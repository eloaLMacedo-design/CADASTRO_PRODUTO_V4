O que é Bootstrap?

Bootstrap é um framework front-end que oferece componentes e estilos prontos para acelerar a criação de interfaces.

Neste projeto, o conceito é demonstrado pela organização de componentes da interface, como botões, formulários e janelas modais. Os modais desta versão foram personalizados com HTML, CSS e JavaScript para combinar com a identidade visual do sistema.
